# J.A.R.V.I.S Gold — جارفس الذهب

نظام مراقبة وتحليل الذهب بالذكاء الاصطناعي — نسخة مستقلة للاستضافة الخارجية.

## المتطلبات

- Node.js 20 أو أحدث + pnpm
- مفتاح Google Gemini API (مجاني من [aistudio.google.com](https://aistudio.google.com/apikey))

## متغيرات البيئة

| المتغير | مطلوب | الوصف |
|---|---|---|
| `GEMINI_API_KEY` | نعم | مفتاح Google Gemini — يشغّل الشات والتحليل والصوت |
| `JWT_SECRET` | نعم | أي نص عشوائي طويل (لتوقيع الجلسات) |
| `PORT` | لا | منصات الاستضافة تضبطه تلقائياً (افتراضي 3000) |

ملاحظة: بيانات الأسعار تُجلب مباشرة من Yahoo Finance المجاني — لا تحتاج أي مفتاح.

## التشغيل محلياً

```bash
pnpm install
pnpm build
GEMINI_API_KEY=your_key JWT_SECRET=any_random_text pnpm start
```

ثم افتح http://localhost:3000

## النشر على Render (مجاني)

1. ارفع هذا المجلد إلى مستودع GitHub
2. في [render.com](https://render.com): New → Web Service → اربط المستودع
3. Render سيقرأ `render.yaml` تلقائياً — فقط أدخل قيمة `GEMINI_API_KEY` عند الطلب
4. اضغط Deploy وانتظر اكتمال البناء

ملاحظة الخطة المجانية: الخدمة تنام بعد 15 دقيقة بدون زيارات وتستيقظ خلال ~30-60 ثانية عند أول زيارة.

## الميزات

- سعر الذهب الحي (XAU/USD عبر عقود COMEX) مع تحديث كل 30 ثانية
- شارت تفاعلي 1H/4H/1D مع SMA/EMA وRSI
- إشارات فنية تلقائية بالعربية مع مستويات الدعم والمقاومة
- تحليل يومي بالذكاء الاصطناعي بالعربية
- شات جارفس: اسأل عن أي أصل مالي (أسهم، كريبتو، عملات) ببيانات حية
- صوت جارفس الإنجليزي الفخم (Gemini TTS — صوت Algenib) مع بديل صوت المتصفح
- وضع LIVE MODE: محادثة صوتية متواصلة بالعربية (يسمعك ويرد صوتياً)
